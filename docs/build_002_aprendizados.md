# Build 002 — Aprendizados

## Contexto

A Build 002 evoluiu a Experiência Zero para uma sala com elementos interativos, buscando reduzir a sensação de questionário e aumentar a exploração.

## Impressões do teste

- A experiência ficou um pouco menos chata que a Build 001.
- Surgiu curiosidade sobre a lógica que liberava o botão para sair da sala.
- A lógica de liberação não ficou clara.
- A repetição do processo sem compreender a lógica gerou cansaço.
- Os botões representavam objetos, mas ainda não pareciam objetos de um mundo interativo.
- A devolutiva comportamental foi percebida como útil, mas limitada à sessão individual.

## Aprendizados principais

### 1. Curiosidade sem clareza vira frustração

A curiosidade sobre a lógica de saída foi positiva no início, mas a falta de pistas compreensíveis transformou a exploração em cansaço.

### 2. Botões não criam mundo

Representar objetos como botões ainda mantém a experiência próxima de uma interface tradicional. Para gerar sensação de mundo interativo, os elementos precisam parecer objetos manipuláveis, com posição, estado, reação e transformação.

### 3. A devolutiva não precisa ser apenas para o jogador

O maior valor da observação comportamental pode estar no banco de dados para o desenvolvedor: mapear interesses, padrões de exploração, pontos de abandono, perfis de comportamento e variações ao longo do tempo.

### 4. O histórico importa mais que a sessão isolada

Uma única sessão gera uma observação limitada. O valor real aparece quando comparamos múltiplas sessões do mesmo usuário e, futuramente, padrões agregados entre usuários diferentes.

## Decisão para Build 003

A próxima build deve deixar de focar em devolutiva ao jogador e começar a estruturar uma camada de análise para o desenvolvedor.

O objetivo passa a ser:

> Transformar a Experiência Zero em uma bancada de teste comportamental, capaz de registrar sessões e revelar padrões de exploração.

## Hipótese da Build 003

> Um painel simples de histórico e análise comportamental será mais valioso para o desenvolvimento do Atlas do que uma devolutiva individual sofisticada para o jogador neste momento.
