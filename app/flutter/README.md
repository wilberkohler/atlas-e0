# Atlas E0 Flutter

Aplicativo Flutter da Experiência Zero. A build atual apresenta a Sala Zero,
uma cena curta de exploração sensorial com observações baseadas nas interações
da sessão, persistência local de histórico e um painel discreto para análise do
desenvolvedor.

## Painel Dev

Na tela inicial, use o botão `Dev` para abrir o histórico local, métricas
agregadas, detalhe das sessões e JSON copiável.

## Rodar localmente

```bash
flutter run -d chrome
```

## Verificações

```bash
flutter analyze
flutter test
flutter build web
```
