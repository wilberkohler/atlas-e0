# Atlas E0 — Experiência Zero

Experiência experimental de tomada de decisão e observação comportamental.

Frase de abertura:

> Toda decisão revela alguma coisa.

## Objetivo

Criar uma experiência curta, de até 5 minutos, em que o jogador toma decisões e recebe uma devolutiva baseada no comportamento observado durante a sessão.

## O que este projeto não é

- Não é um teste de personalidade.
- Não é um quiz tradicional.
- Não é um jogo baseado em pontuação, vitória ou derrota.
- Não é uma classificação definitiva sobre quem o jogador é.

## O que este projeto é

É a primeira experiência prática do Atlas para testar o conceito de **Espelho Cognitivo**: um sistema que observa decisões, tempos de resposta e padrões de interação para devolver ao jogador percepções sobre como ele decidiu durante a experiência.

## Princípio central

O sistema não diz: "você é assim".

O sistema diz: "durante esta sessão, observei isto".

## MVP inicial

- Tela de abertura.
- Cinco situações de decisão.
- Registro simples de eventos.
- Tela final com três observações comportamentais.

## Métricas iniciais

- Tempo em cada decisão.
- Opção escolhida.
- Ordem das escolhas.
- Repetição da experiência.
- Padrões simples de hesitação, curiosidade e engajamento.

## Status

Projeto em estruturação inicial.
